Project Overview

This project demonstrates how to design and implement a relational database using SQLite and Python. The goal is to organize workshop information and attendee registrations while maintaining data integrity.

Database Design

The database contains two related tables:

1. Workshops

* Stores workshop codes, titles, dates, locations, formats, instructors, and capacities.
* Uses a primary key to identify each workshop.
* Applies UNIQUE and CHECK constraints to validate data.

2. Attendees

* Stores attendee names, email addresses, and workshop registrations.
* Uses a foreign key to connect each attendee to a workshop.
* Prevents duplicate registrations for the same workshop and email address.

Project Files

* schema_sketch.png – Database relationship diagram.
* schema.sql – SQL statements for creating the database tables.
* load.py – Python script for importing and validating CSV data.
* workshop_signups.csv – Original workshop registration dataset.
* workshops.db – SQLite database generated by the Python script.

Data Import Results

The Python script processed the CSV file and generated the following results:

* Workshops inserted: 8
* Attendees inserted: 35
* Rejected rows: 2

One row was rejected because of incomplete attendee information. Another was rejected because it violated the UNIQUE constraint.

How to Run

3. Open a terminal in the project directory.
4. Run python load.py.
5. Review the console output and generated SQLite database.
